# Xining Ran — Personal Research Homepage

A lightweight academic homepage built with plain HTML/CSS, ready for GitHub Pages.

## Publish
1. Create a GitHub repository named `<YOUR-GITHUB-USERNAME>.github.io`.
2. Upload `index.html` to the repository root and commit the change.
3. Open **Settings → Pages** and select deployment from the `main` branch, root (`/`).
4. Visit `https://<YOUR-GITHUB-USERNAME>.github.io`.

Replace the repository placeholder with your actual GitHub username. The site is public once published.
